### 📱 Featured Project: Habit Tracker - Us+

Co-created and launched on Google Play. Us+ was built on a simple truth: most habit trackers fail because building routines in isolation is lonely. We created a platform centered around social accountability to make staying consistent easier and more engaging.

**Key Features & Technical Implementation:**
- 🤝 **Shared Goals & Real-time Sync:** Track shared habits with partners using Supabase Realtime.
- 🎨 **Interactive Engagement:** Send dynamic GIF reactions powered by KLIPY integration.
- 📱 **Native Android Widget:** Custom native home screen widget built in Kotlin to log habits in a single tap.
- 🔔 **Notifications & Subscriptions:** FCM push notifications & In-App Subscriptions managed via RevenueCat.

👉 [Check it out on Google Play](https://play.google.com/store/apps/details?id=dev.tesserly.usplus)
